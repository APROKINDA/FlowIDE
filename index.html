HOW TO USE YOUR COMMANDS

          

            
    
              
  1. Choose a name, for example Alert.
    2. 
              
  2. Choose Show browser alert and keep the argument count at 1.
    3. 
              
  3. Tap Add command. The command is saved in this browser.
    4. 
              
  4. Open Script and write Alert("Hello from Flow!").
    5. 
              
  5. Tap Check to validate it, then Run to show the alert.
    6. 
            

            
Arguments are Flow expressions, so variables also work: Alert(PlayerName). Custom commands are included in a .flowproj export. They are local to this browser unless you share/import a project that contains them.

            
Action reference and examples

            
Choose the action, set the exact argument count, then call the command with values. Values can be literal text, numbers, booleans, or existing Flow variables.

            
    
              
  • Alert("Hello") — browser popup; one argument.
    • 
              
  • Ask("Your name?") — prompt input; one argument.
    • 
              
  • Print("Hello"), Warn("Careful"), ErrorMsg("Oops") — console output; one or more arguments.
    • 
              
  • SetStatus("Building") — editor status; one argument.
    • 
              
  • SpawnCube("Player"), SpawnSphere("Orb"), SpawnPlane("Ground") — create 3D objects; one name argument.
    • 
              
  • SpawnRect("Panel"), SpawnCircle("Ball") — create 2D shapes; one name argument.
    • 
              
  • DeletePicked() — delete selected asset; zero arguments.
    • 
              
  • RenamePicked("Hero") — rename selected asset; one argument.
    • 
              
  • MovePicked(10, 20, 0) — set selected position; three numeric arguments.
    • 
              
  • ScalePicked(2, 2, 2) — set selected scale; three numeric arguments.
    • 
              
  • RotatePicked(45) — rotation in degrees; one numeric argument.
    • 
              
  • ColorPicked("#ff00aa") — selected asset color; one hex-color argument.
    • 
              
  • ShowPicked(true) or ShowPicked(false) — visibility; one boolean argument.
    • 
              
  • Use2D(), Use3D() — switch workspace; zero arguments.
    • 
              
  • ClearLog() — clear Flow Console; zero arguments.
    • 
            

            
Commands are stored in this browser and travel with exported .flowproj projects. These actions are prebuilt engine operations; adding a brand-new engine capability still requires a trusted handler in the engine code.
